# downside-risk-portfolio-optimization

# Downside Risk Portfolio Optimization

## Master's Thesis Project

**Master's Degree in Finance and Business**
**Roma Tre University**
**Author: Alessandra Farina**

This repository presents the methodology, main findings, and abstract of my Master's thesis:

**"Beyond Variance: A Monte Carlo Analysis of Downside Risk in Portfolio Selection"**

## Project Overview

This project investigates whether downside risk can provide a more effective representation of financial risk than the traditional variance-based approach to portfolio selection.

The analysis compares two portfolio optimization frameworks:

* **Mean-Variance (MV)**, which considers the overall variability of returns;
* **Downside-Efficient (DE)**, which focuses specifically on returns falling below a target level.

The main objective is to assess how the choice of risk measure affects portfolio allocation and exposure to extreme losses, particularly when return distributions are asymmetric and affected by default risk.

## Methodology

The empirical analysis was developed in **MATLAB** using Monte Carlo simulations.

The model considers **five risky assets and one risk-free asset**. Risky-asset returns are generated by combining a lognormal component with a Bernoulli default component, allowing increasingly asymmetric return distributions and more pronounced downside tails to be simulated.

Three market scenarios are analysed:

1. **Lognormal** – no default risk;
2. **Jarrow** – moderate and differentiated default probabilities;
3. **Dangerous** – higher default probabilities representing a stressed financial environment.

The Mean-Variance portfolio is obtained using the covariance matrix of asset returns.

The Downside-Efficient portfolio is instead based on a **downside-cosemivariance matrix**, which considers co-movements between assets specifically in scenarios where portfolio returns fall below the target level.

Because this matrix depends on the portfolio itself, the Downside-Efficient solution is obtained through an iterative **fixed-point algorithm**.

The two approaches are then compared at the **same expected return**, allowing differences in risk and tail behaviour to be evaluated consistently.

## Monte Carlo Analysis

The main simulations were performed using **100,000 observations**.

Additional analyses were conducted to assess:

* estimation error of covariance and downside-cosemivariance matrices;
* robustness of portfolio risk measures;
* sensitivity to sample size;
* sensitivity to default intensity;
* robustness across different random seeds.

A simulation of **1,000,000 observations** was also used as a numerical benchmark in the robustness analysis.

## Risk Measures

The portfolios were evaluated using several risk and tail-risk indicators, including:

* Standard Deviation
* Downside Risk
* Maximum Loss
* 1% Quantile
* Expected Shortfall at 1%
* Probability of Severe Losses

## Main Findings

When default risk is absent, the Mean-Variance and Downside-Efficient approaches produce very similar portfolio allocations and risk profiles.

As default probabilities increase, the differences become more pronounced. The Downside-Efficient portfolio tends to allocate more weight to assets with lower default probabilities and reduce exposure to assets characterized by more severe downside outcomes.

At the same expected return, the Downside-Efficient approach provides better protection in the left tail of the return distribution, reducing the severity of extreme losses. The advantage becomes progressively more relevant as default intensity increases, particularly in terms of Expected Shortfall and other extreme-loss indicators.

Sensitivity and robustness analyses confirm that the main findings remain stable across different sample sizes and random seeds.
